# CORAL BAY HEAT — Make GTA 6

Rebuild v17 (23 Nov 2026): full in-session rewrite — light pool centred on the hero car, burning van closer with bigger flames, warmer dusk lighting, detailed hero/police/NPC models, polished HUD. Playtest 2/2 green, kit check 4 passed.

A complete, original 3D open-world crime game that runs in a desktop browser. You are the wheelman in Coral Bay: outrun the heat, hold the sand, and own the city.

- High-speed police chase down the coastal highway — cruisers boxing you in, a helicopter overhead, its searchlight pinning your hero car
- On-foot shootout on the sand: the red-jacketed protagonist, police officers closing in, a fallen officer, a burning police van
- 8 story missions with a wanted system (3 stars), a weapon store, garage upgrades, and a living island map
- Full HUD: minimap, health, wanted stars, cash, mission tracker, and a career stats screen with save slots

## Play

Open `game/index.html` in desktop Chrome — no install, nothing to download beyond the page itself.

## Build the hand-in

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22) copies `game/` and `screenshots/` into the output directory and writes `dossier.json`, the summary the judge reads.
